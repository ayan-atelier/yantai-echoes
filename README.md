# 🎲 重Roll助手 (`yantai-echoes`)

一个简单、无感的 **SillyTavern（酒馆）历史楼层重Roll回看与分支管理插件**。

在正常游玩和阅读上文时 **100% 保持酒馆原生无痕外观**（只在楼层右下角保留原生样式的 `< 2/3 >` 页码）；当你主动点击某楼的 `<`、`2/3` 或 `>` 查看时，自动在该楼底部展开极简三排工具栏，让你和朋友在重 roll 几十次并继续往后推进剧情后，依然能随时回去翻看、收藏、备注、隐藏、在旧楼层重 roll 或一键切出平行新分支，**100% 不影响当前存档进度与 AI 上下文**。

---

## 一键安装

在 SillyTavern 顶部打开 **扩展 (Extensions) -> 安装扩展 (Install extension)**，填入以下 GitHub 仓库地址即可安装：

```text
https://github.com/ayan-atelier/yantai-echoes
```

---

## 核心特性

1. **平时 100% 原生无痕，翻看时自动浮现极简三排工具栏**
   - 平时阅读时，页面上没有任何多余悬浮窗或突兀按钮，历史楼层右下角与最后一段保持同款 `< 2/3 >`。
   - 一旦点击某楼的 `<`、`2/3` 或 `>`，该楼底部自动浮现三排快捷栏：
     - **第 1 排**：`当前 #3/3（仅预览）` + `↩ 回到原路 #2`（或 `✕ 收起`）
     - **第 2 排**：`[☰ 全部 (N)]` + `[🌿 保存并开启新分支]`
     - **第 3 排**：`[★ 收藏]` + `[✎ 备注]` + `[🙈 隐藏本条]` + `[🎲 重 roll]`
2. **100% 存档与上下文安全（无损回看）**
   - 在历史楼层翻页或重 roll 默认均为**仅预览**（页码显示 `3/3*`），不改动该楼底层生效的 `mes` 与 `swipe_id`。
   - 继续向下发送消息时自动还原预览，哪怕该楼在预设读取的最近楼层范围内，AI 读取的也始终是你原本选定的路线。
   - 完美兼容 **酒馆助手 (`JS-Slash-Runner`)** 前端 HTML 状态栏与各类正则美化，翻页与重 roll 秒出状态栏无需手动刷新。
3. **历史楼层直接重 roll + 防误触保护**
   - 支持在任意过去的楼层直接点击 `[🎲 重 roll]` 生成新的重 roll 分支，后续所有楼层完好无损。
   - 历史楼层最后一页点击右箭头 `>` 默认先展开工具栏并高亮提示 `[🎲 重 roll]`，防止手滑误触 API 生成。
4. **一键「保存并开启新分支」**
   - 回看旧楼层的某条重 roll（路线 B）心痒想试时，点一下 `[🌿 保存并开启新分支]`，即可将当前完整进度（路线 A）安全保存，并自动以路线 B 为起点创建、打开新的平行分支存档继续往下玩。
5. **收藏、备注、假删除（隐藏本条）与防误删保护**
   - 支持给每条重 roll 标星收藏、写简短备注、或一键「隐藏本条」（翻页时自动跳过，随时可在 `全部 -> 已隐藏` 中恢复）。
   - 自带「重新生成 (Regenerate)」防误删保护，点击菜单重新生成时自动抢救并保留本楼之前所有的重 roll 记录。
